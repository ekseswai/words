# 单词本

一个简洁的个人英语单词网站。注册本地账号后，单词会保存在当前浏览器中。

## 功能

- 添加英文单词和中文释义
- 英文或中文关键词搜索
- 依英文首字母 A-Z 分组及排序
- 同一账户内不区分英文大小写的重复拦截
- 自由注册用户名与密码
- 按账号隔离的本地词库
- 一键生成中文意思，并可手动修改

## 使用方式

1. 首次使用时，输入至少 3 个字符的用户名和至少 6 位的密码，点击“没有账号？注册”后创建账号。
2. 注册完成后使用该用户名与密码登录。
3. 单词数据和账号信息仅保存在本机当前浏览器的 localStorage 中；清除浏览器网站数据会将其删除，且不会自动同步到其他设备。
4. 输入英文单词后可点击“自动生成中文意思”。该功能会请求免费的 MyMemory 翻译服务，服务不可用或限流时仍可手动填写。

## 部署建议

可直接部署到 GitHub Pages、Vercel 或 Netlify；访问 `index.html` 进入登录页，登录成功后会跳转至 `wordbook.html`。这是一个没有构建步骤的静态网站。
